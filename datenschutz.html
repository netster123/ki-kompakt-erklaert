Datenschutzerklärung

Diese Erklärung gilt für das interne Werkzeug „KI kompakt erklaert Upload“, mit dem der Betreiber seinen eigenen YouTube-Kanal „KI kompakt erklärt“ verwaltet. Stand: 14. November 2026.

Wer nutzt das Werkzeug?

Ausschließlich der Betreiber des Kanals selbst. Es gibt keine weiteren Nutzer und keine öffentliche Anmeldung.

Welche Daten werden verarbeitet?

Über die YouTube Data API (Google) greift das Werkzeug nur auf den eigenen Kanal zu, um

  • eigene Videos hochzuladen,
  • Titel, Beschreibungen, Schlagwörter, Vorschaubilder und Veröffentlichungszeiten eigener Videos zu setzen,
  • die Liste der eigenen Videos und Playlists anzuzeigen.

Es werden keine Daten anderer Personen abgefragt, gespeichert oder ausgewertet.

Speicherung

Der Zugangsschlüssel (Token) von Google wird nur lokal auf dem Computer des Betreibers gespeichert. Es gibt keinen eigenen Server und keine Datenbank. Daten werden nicht an Dritte weitergegeben oder verkauft.

Google und YouTube

Das Werkzeug nutzt die YouTube API Services. Es gelten die Nutzungsbedingungen von YouTube und die Datenschutzerklärung von Google.

Zugriff widerrufen

Der Zugriff kann jederzeit in den Google-Kontoeinstellungen unter Drittanbieter-Apps mit Kontozugriff widerrufen werden. Danach löscht der Betreiber den lokal gespeicherten Schlüssel.
